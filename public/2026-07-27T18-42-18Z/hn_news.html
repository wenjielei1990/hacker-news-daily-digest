Removing React.js from the codebase and adapting Htmx for UI interactivity (2023) HN 讨论 · 115

Misago 论坛宣布决定从代码库中移除 React.js，转而采用 HTMX 来处理 UI 交互。此前该项目采用 Django 渲染初始页面、React 进行二次挂载的混合模式，导致了严重的重复开发和性能开销。开发者指出，维护两套模板不仅增加了复杂度，还让插件开发变得异常困难。HTMX 允许通过声明式属性直接在 HTML 中定义动态区域，由服务器返回局部 HTML 片段进行替换，无需复杂的 JSON 序列化。这种回归“服务器渲染”的模式非常适合论坛这种交互相对孤立的场景，能显著减小 JS 体积。不过，对于需要极高实时性或复杂 DOM 状态管理的富交互功能，HTMX 仍存在局限。

展开详情 ↓

Misago 论坛目前面临着“双重实现”的困境：每一个页面和视图都需要同时编写 Django 模板和 React 组件。这种架构导致用户在加载页面时会先看到 Django 渲染的内容，随后被 React 替换，产生明显的闪烁感，且在低端设备上性能较差。此外，为了支持 React，后端必须维护复杂的 API 和 JSON 序列化逻辑，这不仅拖慢了响应速度，还让多语言翻译文件的管理变得冗余。对于插件开发者而言，必须同时掌握两套技术栈才能扩展功能，极大地提高了开发门槛。

转向 HTMX 后，Misago 将回归以服务器为中心的开发模式。HTMX 的核心理念是利用 HTML 属性来触发 AJAX 请求，并直接用服务器返回的 HTML 片段更新页面的特定部分。这种方式消除了对大型 JavaScript 框架的依赖，减少了前端打包体积，并让后端逻辑重新统一到 Django 模板中。虽然这种做法在理念上类似于早期的 jQuery 或 Rails Turbolinks，但它在声明式语法和局部刷新上更加现代化，能有效处理论坛中的回帖、投票和通知等交互。

然而，这种转型也并非没有挑战。HTMX 在处理需要精细 DOM 操作的场景（如富文本编辑器或复杂的实时滚动列表）时，可能会遇到滚动位置丢失或响应延迟的问题。开发者计划在必要时配合 Web Components 或轻量级的 Alpine.js 来处理这些客户端状态。未来，Misago 将重点优化服务器端的局部渲染效率，以确保在移除 React 后依然能提供流畅的用户体验，同时大幅降低系统的维护成本。

谢伊式机车（Shay Locomotive）是一种独特的齿轮传动蒸汽机车，主要活跃于19世纪末至20世纪中叶。与传统机车不同，它采用垂直气缸驱动侧置传动轴，通过齿轮带动所有车轮。这种设计赋予了它极强的牵引力和灵活性，能够应对极陡的坡度和简陋、多弯的临时轨道。它曾是伐木和采矿行业的支柱，解决了当时重型卡车尚未普及时的运输难题。然而，齿轮传动限制了其最高速度，使其无法胜任长途客运任务。该网站记录了历史上生产的2770台谢伊机车的详细档案，是研究工业遗产的重要资源。

展开详情 ↓

谢伊式机车由埃弗拉伊姆·谢伊（Ephraim Shay）于1881年获得专利，其设计完全颠覆了传统蒸汽机车的对称美学。为了在崎岖的林区和矿山中运行，它放弃了巨大的驱动轮，转而采用一套复杂的齿轮传动系统。最显著的特征是其气缸垂直安装在车身右侧，为了平衡重量，锅炉不得不向左侧偏移。这种非对称布局虽然看起来古怪，却能让所有车轮都成为驱动轮，提供巨大的扭矩和抓地力。

这种机车在工业史上的重要性在于它对恶劣环境的适应力。它能爬上坡度高达14%的陡坡（标准铁路通常难以超过4%），并能在铺设简陋、甚至没有路基的临时铁轨上平稳运行。在重型卡车和现代化筑路设备出现之前，谢伊机车是深入荒野提取资源的唯一手段。尽管其速度极慢，通常不超过每小时20公里，但在伐木场这种对通过能力要求极高的地方，它是无可替代的。目前全球仅存约116台，部分仍在旅游铁路上运行，作为那个时代机械智慧的见证。
