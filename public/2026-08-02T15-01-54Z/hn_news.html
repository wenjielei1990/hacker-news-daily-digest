Go 1.27 带来了一系列重量级更新，其中“泛型方法”是核心亮点。开发者现在可以为结构体方法定义独立的类型参数，例如在容器类型上直接实现 Map 操作，而不再需要依赖包级别的全局函数。不过，这一特性存在重要限制：接口仍然不能声明泛型方法，且带有泛型方法的方法集无法用于满足接口。在语法糖方面，结构体字面量现在支持直接设置提升字段（promoted fields），无需再嵌套编写嵌入的结构体类型。此外，函数类型推断也得到了泛化，在复合字面量和类型转换中表现得更加智能。

Meshdiff 的核心价值在于简化了 3D 文件的版本校验流程。在 3D 打印和工业设计领域，设计师经常需要处理命名混乱的文件（如“最终版_v3”），很难快速识别微小的几何改动。该工具允许用户直接在浏览器中拖入两个模型，利用 Web Worker 在本地完成计算，并提供 0.05mm 到 1mm 的可调容差以及体积变化指标。技术上，它采用了 React Three Fiber 和自定义体素引擎，而非依赖 Manifold 或 CGAL 等对拓扑结构要求极高的库，这使其能够处理现实中常见的、带有拓扑缺陷的“三角形汤”模型。

I made a Promise-aware debounce and throttle library for TypeScript HN 讨论 · 4

Temporize 是一个专为 TypeScript 开发的轻量级定时与并发控制库，旨在解决传统工具在异步环境下的局限。与 Lodash 等库不同，它的防抖（debounce）和节流（throttle）函数会为每次调用返回一个真实的 Promise，从而直接获取异步执行结果。该库支持多种高级功能，包括请求批处理、带指数退避的重试机制、并发频率限制以及针对 React 和 Vue 的原生适配器。它特别强化了对异步重叠的处理，允许开发者在多个异步任务冲突时选择排队、丢弃或取消。库本身无运行时依赖，且每个核心模块体积均控制在 1kB 以内，非常适合追求极致性能的现代 Web 应用。

展开详情 ↓

Temporize 填补了 JavaScript 异步编程中的一个常见痛点：传统的防抖和节流工具（如 Lodash）通常只返回上一次的同步结果或 undefined，这使得在现代 async/await 流程中集成它们变得非常别扭。Temporize 通过让每一次调度调用都返回一个代表该次执行结果的 Promise，实现了完整的类型推断和错误传播。它引入了 `debounceAsync`，提供了“排队”、“丢弃”和“取消前一个”三种策略来处理并发的异步任务，并能通过 AbortSignal 实现协作式取消。这种设计让开发者能够精确控制异步逻辑在时间轴上的重叠行为。

除了基础的定时功能，该库还涵盖了从 requestAnimationFrame 节流到 requestIdleCallback 调度的全套工具。对于高性能场景，它提供了参数批处理（batch）功能，能将短时间内的多次调用合并为一次 API 请求，并为每个原始调用者分发结果。此外，它还内置了并发限制器（concurrencyLimit）和支持随机抖动的指数退避重试机制。Temporize 采用 ESM 和 CommonJS 双重格式，具有极高的树摇（tree-shaking）效率。虽然它提供了 React 和 Vue 的 Hook 适配器，但这些都是可选的对等依赖，确保了核心库的零依赖特性和极小的体积占用。
