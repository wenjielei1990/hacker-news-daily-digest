Go 1.27 正式发布，带来了语言规范、工具链和运行时的多项重大更新。最显著的变化是支持了泛型方法，允许在结构体方法中使用类型参数，从而简化了如随机数生成等 API 的设计。结构体字面量现在可以直接初始化嵌套或嵌入的字段，提高了代码的可读性。此外，泛型函数的类型推断范围扩大，在复合字面量和通道发送等场景下不再需要显式指定类型。虽然这些特性提升了开发效率，但也标志着 Go 语言在功能复杂度上的进一步增加。

展开详情 ↓

Go 1.27 版本在泛型支持上取得了关键进展，正式引入了泛型方法（Generic Methods）。这意味着开发者不再需要为不同的数据类型编写重复的结构体方法，例如 `math/rand/v2` 现在可以使用统一的泛型方法处理所有整数类型。同时，类型推断机制得到了增强，现在可以应用于所有的赋值上下文，使得泛型函数在复合字面量初始化、类型转换以及通道发送时，能够自动推断类型参数而无需手动声明。

在语法便利性方面，新版本允许在结构体字面量中使用字段选择器作为键，这意味着可以直接初始化嵌套结构体或嵌入结构体中的字段，减少了构建复杂对象时的层级嵌套感。工具链也迎来了更新：`go fix` 增加了多个“现代化”迁移工具，帮助开发者自动升级到新的原子类型和切片操作；`go mod tidy` 则能自动整理 `go.mod` 文件结构，将依赖项统一归类。尽管这些改进增强了语言的表达能力，但社区也开始关注这些新特性对编译速度以及 Go 语言一贯坚持的“简单”哲学所带来的潜在挑战。

Google 改变了部分 Android 和 Pixel 源代码的分发方式，不再通过 Git 标签直接发布。开发者现在必须填写 Google 表单申请，并等待人工发送 Google Drive 下载链接。GrapheneOS 指出这种做法极大地降低了获取代码的效率，并认为这违反了 GPLv2 协议。这一变化增加了第三方 ROM 维护者的负担，使其难以同步最新的安全修复。尽管 Google 仍提供代码，但这种增加摩擦力的做法被视为对开源精神的背离。目前这一限制主要影响特定硬件相关的底层代码，而非整个 Android 框架。

展开详情 ↓

根据 GrapheneOS 的披露，Google 已停止为某些关键源代码（特别是与 Pixel 设备相关的部分）推送 Git 标签。在传统的开发流程中，开发者可以通过 Git 命令直接拉取特定版本的代码，但现在这一过程被一个繁琐的手动流程取代：开发者需要提交 Google 表单申请，然后等待 Google 员工通过 Google Drive 分享源代码。这种转变不仅让自动化构建变得困难，还因为人工审核的延迟导致第三方开发者获取代码的速度大幅下降。

这种做法引发了关于 GPLv2 协议合规性的激烈讨论。虽然 GPL 要求分发者提供源代码，但并未严格规定分发的技术手段，Google 这种“手动申请”模式在法律上可能处于灰色地带，但在实践中被视为一种阻碍。GrapheneOS 提到，Google Drive 提供的通常是巨大的压缩包，其内部结构与 Android 构建系统预期的多仓库布局不符，进一步增加了集成难度。这被认为是 Google 进一步收紧 Android 生态控制权的信号，旨在通过增加技术门槛来削弱第三方定制系统的竞争力。未来，开发者可能需要依赖像 GrapheneOS 这样自行维护镜像的组织，或者被迫转向更开放的硬件平台。

这是一个专门记录全球“压币机”（Penny Press）位置的互动地图网站。压币机常见于博物馆、动物园等旅游景点，游客通过机械挤压将分币加工成印有特定图案的扁平纪念币。这种纪念品因价格低廉、不占空间且具有“到此一游”的实物证明属性，拥有庞大的爱好者群体。该网站由社区驱动，详细标注了各地的机器状态和图案样式。然而，随着分币在多国逐渐退出流通，以及移动支付的普及，这种传统机械装置正面临被预装硬币的电子机型取代的挑战。

pennypresses.net 是一个充满“老派互联网”气息的工具网站，旨在为全球压币机爱好者提供详尽的地理索引。压币机（又称拉长币机）的操作通常涉及将一枚分币（如美国 1 美分）和几枚支付币放入机器，通过手动转动摇杆，利用高压将分币压扁并模刻上景点的标志性图案。对于收藏者而言，这不仅是廉价的纪念品，更是一种参与式的体验。网站不仅提供了地图搜索功能，还记录了每台机器提供的具体图案，帮助发烧友有针对性地打卡收藏。

在技术层面，资深玩家非常看重硬币的材质。1982 年以前生产的美国分币含有 95% 的铜，压制出的效果色泽金黄且图案清晰；而之后的硬币主要成分为锌，压制时容易出现银色的条纹或裂痕。为了获得最佳效果，玩家甚至会使用番茄酱等弱酸性物质提前清洗硬币。目前，这一行业正处于转型期，许多新式机器不再要求玩家自备硬币，而是接受信用卡支付并自动提供预制的锌币或代币。此外，法律风险也是一个话题，虽然在美国出于纪念目的损毁货币是合法的，但在澳大利亚等国家，损毁流通货币仍被视为违法行为，这限制了此类机器在全球的普及。

智慧 @ssl-3

作为一个路过压币机必压的人：任何旧铜币都可以。选你手里最干净的那枚。1982 年以前的分币能达到最高的清晰度。硬币磨损严重或纹路清晰都没关系，反正那些特征都会被压平。（1982 年以后的硬币主要是锌做的，压出来的效果往往比较模糊，虽然也有种独特的美感，但那不是你想要的。）有时旧硬币上的污垢会碍事，你可以先洗洗。去旅游景点随处可见的厕所里用肥皂水洗一下，把它刷亮。你甚至可以抛光它。钱币收藏家讨厌化学抛光，但反正他们也不会被邀请参加这种压币派对。有很多东西可以把铜擦得闪闪发亮，而且在外面很容易找到。比如旁边汉堡店的番茄酱：把番茄酱涂在已经比较干净的硬币上，番茄酱里的酸只需几分钟就能让它变得粉红透亮。（这招对铜底锅也管用。）如果是那种收信用卡、自带硬币的新式机器，那也没关系：直接压，以后再清洗或抛光。

LLM 锐评

在数字化收藏品（如 NFT）热度退去的今天，像 pennypresses.net 这样记录纯物理、低技术含量爱好的网站显得格外珍贵。它不仅是一个地理数据库，更是对一种即将消失的机械交互文化的致敬。随着各国货币体系逐渐去现金化，这种依赖物理分币的“模拟时代遗迹”正面临生存危机。正如评论区所言，这种网站代表了互联网最初的模样：一个人因为热爱某种微小的细分事物，便不计回报地为其建立索引。这种“无用之用”的浪漫，或许正是技术社区最怀念的特质。
