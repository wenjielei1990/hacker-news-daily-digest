.name Termination HN 讨论 · 401

域名注册局 Verisign 提议并获 ICANN 批准，将终止所有 .name 后缀的三级域名注册（如 user.surname.name），旨在简化管理。这一变动将影响约 2.2 万名长期用户，导致他们的个人网站、电子邮件和关联的 IoT 设备在 2027 年初失效。最严重的风险在于，一旦三级域名被注销，对应的二级域名（如 surname.name）将开放注册。新持有者可以轻易重建原有的三级邮件地址，从而通过重置密码等手段劫持原用户的各类互联网账号。尽管二级域名本身不受影响，但这种单方面终止服务的行为引发了对互联网身份稳定性的巨大担忧。

展开详情 ↓

根据 Neil Fraser 的博文，Verisign 已获准清理 .name 顶级域中的三级域名结构。这一结构最初设计是为了让个人能以“名.姓.name”的形式拥有独特的互联网标识，但 Verisign 以“简化行政管理”为由提议将其彻底废除。ICANN 已于 2026 年 7 月批准了这一请求，这意味着像 Fraser 这样使用了 25 年的域名将在 2027 年 2 月失效。受影响的用户不仅会失去个人主页和 API 服务，更面临严重的身份安全威胁：由于三级域名注销后，其所属的二级域名将进入公开市场，恶意注册者可以购买这些二级域名并恢复旧的邮件地址，进而接管与该邮箱绑定的数千个第三方账户。Fraser 指出，Verisign 在申请中声称此举对域名生命周期“没有影响”，这显然是误导性的。目前，受影响的用户群体正考虑通过法律手段维权，而此事件也再次引发了关于域名作为“租赁资产”而非“永久所有权”的脆弱性讨论。对于那些依赖三级域名构建数字身份的人来说，这无异于一场数字身份的“强制拆迁”。

Cerebras Inference 宣布在其平台上推出 Qwen 3.8 27B 模型，利用其专有的晶圆级硬件实现了 1500 tokens/s 的推理速度。这种速度比传统的 GPU 推理快了一个数量级，能够为用户提供几乎没有延迟的“即时”反馈感。Qwen 3.8 27B 本身是一款在编程和逻辑推理方面表现出色的开源模型，其在 Cerebras 上的部署进一步推高了高性能推理的门槛。

然而，极速推理也带来了显著的权衡。多位开发者指出，由于 Cerebras 目前不支持 Prompt 缓存，在进行 Agent 模式或迭代编程任务时，每次请求都需要为完整的上下文付费，这导致成本迅速攀升，甚至比其他平台贵出数倍。此外，公共 API 的速率限制（如每分钟 150k 或 450k tokens）在如此高的速度下变得非常脆弱，用户往往在几分钟内就会因为触及上限而被锁定。有测试显示，虽然生成速度极快，但输入处理（TTFT）和工具调用（Tool Call）的稳定性仍有待提高。

目前，这种极速推理更像是一种技术展示。对于需要频繁读取和理解代码的开发者来说，1500 tokens/s 的速度往往超过了人类的阅读极限，而缺乏缓存带来的经济压力使得它在生产环境中的竞争力受到挑战。未来值得关注的是 Cerebras 是否会引入缓存机制以降低长对话成本，以及其硬件架构在更大规模模型上的表现。
